# 批量图片等比例缩放工具 · Batch Proportional Image Resizer

两步式批量图片处理工具：

- **step1 规范素材尺寸**：把杂乱源图**纯等比缩放**归一化到固定宽度档位（不裁剪、不拉伸、不填充），便于后续人工裁成 16:9。
- **step2 半自动裁剪**：逐张用 16:9 框取景，一键导出大 / 中 / 小三档成图。

- 中文名：批量图片等比例缩放工具
- 英文名：`batch-proportional-image-resizer`

本仓库提供两个入口：

1. **图形界面版（推荐）** `batch_proportional_image_resizer.py`：step1 + step2 合并为同一工具，本 README 的主要介绍对象。
2. **命令行版（仅 step1）** `adaptive_image_resizer.py`：纯 CLI 的分档缩放器，规则见文末「命令行版」一节。

命令行版特性：

- **按源宽分档**：`>2560 → 2560`(large)、`1920–2560 → 1920`(medium)、`1280–1920 → 1280`(small)
- **高度兜底**：算出来高度 `<720` 时，强制把高拉到 `720`、宽按比例重算（优先于宽封顶，允许宽 `>2560`）
- **不放大保护**：`w<1280 且 h>=720` 时直接保持原尺寸
- **等比、不裁、不拉伸**：使用 PIL 的 `LANCZOS` 重采样
- 支持 `jpg / png / webp / bmp / tif`
- `--sort` 按 `large / medium / small / kept` 分目录，便于按档人工裁 16:9
- `--recursive` 可递归子目录
- **跨 Pillow 版本兼容**：内置 `LANCZOS` 兼容垫片，Pillow 9/10/11/12 都能跑，无需锁定特定版本

## 图形界面版（step1 + step2 合并）

入口：`batch_proportional_image_resizer.py`（单文件，tkinter + Pillow）。

### 运行

```bash
pip install pillow
python batch_proportional_image_resizer.py
```

> tkinter 是 Windows 官方 Python 自带的标准库，无需额外安装。Mac/Linux 若缺 tkinter，用系统包管理器补装即可。

### 界面（三栏）

| 区域 | 内容 |
| --- | --- |
| 左栏顶部 | **「导入 / 规范素材」板块**：导入文件夹 / 导入文件按钮、「已导入 N 条素材图」计数、规范状态提示 |
| 左栏下方 | **素材队列**：只展示 `规范素材图/` 内容（标题显示「待裁剪 N / 共 M」），支持 ↑↓ 调序、点选跳图 |
| 中栏 | 画布：fit-to-window 整图预览，窗口缩放 / 最大化时实时重新适配 |
| 右栏 | 结果放大预览、尺寸套装（三档可编辑）、⚪套装开关、自定义框、旋转 / 镜像 / 居中、格式与质量 |

### 工作目录（自动建在 exe 同目录）

| 文件夹 | 作用 |
| --- | --- |
| `规范素材图/` | step1「规范素材尺寸」的输出，**也是 step2 唯一输入源** |
| `修改后成图/` | step2 裁剪结果导出目录 |
| `规范素材图/返工/` | 按 `1` 把「上一张」退回此处待二次编辑 |
| `修改后成图/精修/` | 按 `3` 把「上一张」结果移入此处待精修 |

### 流程

1. **导入**：左栏点「导入文件夹 / 导入文件」，或直接**从资源管理器拖图进窗口**（源图留在原位置，不复制）。板块会显示「已导入 N 条素材图」。
2. **规范素材尺寸**：点顶栏按钮，对导入的源图做**纯等比缩放**，结果写入 `规范素材图/`，队列随即出现这些图。
3. **裁剪（step2）**：画布上拖动 / 缩放取景框，按**空格**确认导出并自动下一张。已导出（结果已存在）的图自动跳过。

### step1 缩放规则（纯等比，不裁不拉伸）

- 源图宽 **< small 档宽（默认 1280）** → 等比**放大**到该宽度，高度按原比例。
- 源图宽 **≥ 1280** → **保持原尺寸不动**。
- 比例永远与原图一致；16:9 的裁剪完全交给 step2。

| 源图 | step1 输出 |
| --- | --- |
| 2560×1707 | 2560×1707（不动） |
| 6000×4000 | 6000×4000（不动） |
| 1300×730 | 1300×730（不动） |
| 800×800 | 1280×1280（放大到宽 1280） |
| 1000×900 | 1280×1152 |
| 900×1600 | 1280×2276（竖图等比放大） |

> small 档宽可在 GUI 右栏编辑（持久化到 `config.json`），step1 的下限随之抬升。

### 预览与取景

- 默认 **fit-to-window 整图预览**，浅灰画布背景，窗口缩放时实时重新适配。
- 裁剪框：**红框 + 内部 3×3 九宫格**，可拖移、四角缩放并锁定 16:9。
- 右侧 **实时结果放大预览** 显示框内实际裁出内容。
- 跨图 **复用锚点中心**：记录上一张框中心的相对比例，下一张自动落位，遇越界回图像中心。

### 尺寸套装

- GUI 内可编辑三档：**大 2560×1440 / 中 1920×1080 / 小 1280×720**（持久化到 `config.json`）。
- **⚪ 套装开关**：
  - 实心（开）：**不放大优先**自动选档——取源图能完整覆盖的最大档，覆盖不了取最小档，COVER 缩放裁出精确档位图（例：1280×1280 的小图落 small 档，不会被放大到 large）。
  - 空心（关）：自由自定义 W×H 裁剪，**不做任何判断**。
- 手动点「用大 / 用中 / 用小」可临时覆盖本张的档位。

### 变换（手动，不识别 EXIF）

`↺ 左转90°` / `↻ 右转90°` / `⇋ 镜像` / `居中 (C)`。

### 快捷键

| 键 | 作用 |
| --- | --- |
| 空格 | 确认裁剪并前进（唯一推进方式） |
| C | 裁剪框一键居中 |
| 1 | 返工：把「上一张」从 `规范素材图/` 移入 `规范素材图/返工/` |
| 3 | 精修：把「上一张」结果从 `修改后成图/` 移入 `修改后成图/精修/` |

> 「上一张」= 刚用空格前进离开的那张；首图无上一张时 `1`/`3` 无操作。焦点在输入框 / 按钮上时快捷键不触发，避免与数字输入冲突。

### 其他行为

- **窗口获得焦点时自动重扫** `规范素材图/`（在资源管理器里增删文件后切回窗口即刷新）。
- 导入后若队列为空，画布只读预览首张源图；此时按空格会提示先「规范素材尺寸」，不会误裁源图。
- 未导入时点「规范素材尺寸」：兜底重新归一化已有 `规范素材图/` 本身。

### 安装与打包

依赖仅 Pillow；如需出 exe，用 PyInstaller 一条命令即可（与命令行版相同）：

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole batch_proportional_image_resizer.py
```

## 命令行版（仅 step1）

### 安装

```bash
pip install -r requirements.txt
# 或
pip install pillow
```

> 图片缩放是硬需求，纯 Python 标准库做不了（没有 JPEG/PNG 解码器和重采样器），Pillow 是必需依赖。

### 用法

```bash
python adaptive_image_resizer.py --input <图片目录> --sort
# 可选参数
#   --output <目录>     指定输出目录（默认在原目录旁生成 adaptive_output/）
#   --quality 90        输出质量（默认 90）
#   --recursive         递归处理子目录
```

CLI 版采用**按宽分档**规则（与 GUI 的 step1 规则不同）：`>2560 → 2560`、`1920–2560 → 1920`、`1280–1920 → 1280`，宽不足 1280 放大到 1280；高度 `<720` 时兜底拉到 720。`--sort` 会把结果按档位分到 `large / medium / small` 子目录，便于按档人工裁 16:9。

## 说明

- 未做 EXIF 方向处理（代码内已留注释，加一行 `exif_transpose` 即可）。
- 支持 `jpg / png / webp / bmp / tif`；跨 Pillow 版本兼容（内置 `LANCZOS` 兼容垫片，Pillow 9/10/11/12 都能跑）。
