# 批量图片等比例缩放工具 · Batch Proportional Image Resizer

![Version](https://img.shields.io/badge/version-1.0.2-blue)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
![Python](https://img.shields.io/badge/python-3.12%2B-green)
![License](https://img.shields.io/badge/license-MIT-green)

两步式批量图片处理工具，中文界面，**纯等比、不裁不拉伸**地统一素材尺寸，再逐张用取景框（默认 16:9）导出成图。适合电商 / 短视频素材的批量规整。

- **step1 规范素材尺寸**：把杂乱源图按**短边夹逼到你设定的档位区间**，纯等比缩放（不裁剪、不拉伸），短边不够就自动放大到最低要求。
- **step2 半自动裁剪**：逐张用取景框确认，一键导出成图，输出尺寸就是你选中的那个档位。

> **本 README 里出现的尺寸 —— 大档 2560×1440、小档 1280×720、16:9、夹逼区间 [720, 1440] —— 都只是出厂默认值的示例。**
> 这些数字在软件右栏「纵横比 / 大档 / 小档」里随时可改，step1 的夹逼区间与 step2 的输出尺寸会自动跟着变。
> 自定义方法见「三、step1 缩放规则」末尾的教程。

## 一、下载使用（无需安装 Python）

1. 到 [Releases](https://github.com/pandipper/batch-proportional-image-resizer/releases/latest) 下载 `batch_proportional_image_resizer.exe`。
2. 把它放到**任意一个空文件夹**里，双击运行。
3. 首次运行会在 exe 同级自动创建：

| 目录 / 文件 | 作用 |
| --- | --- |
| `规范素材图/` | step1 的输出，**也是 step2 的唯一输入源** |
| `修改后成图/` | step2 的裁剪导出结果 |
| `config.json` | 档位、比例、字号、主题等个人设置 |

> 整个工具是**绿色单文件**：换机器时把这个文件夹整个拷走即可，不会往系统目录写东西。
> Windows 可能弹出 SmartScreen 提示（未签名的个人开发者程序），点「更多信息 → 仍要运行」。

## 二、三步走完一批图

1. **导入**：左栏点「导入文件夹 / 导入文件」，或直接从资源管理器把图片拖进窗口（源图留在原位置，不会被复制或改动）。
2. **规范素材尺寸**：点顶栏按钮，工具对全部源图做纯等比归一化，结果写入 `规范素材图/`，左栏素材队列随即出现这些图。
3. **裁剪导出**：在画布上拖动 / 缩放取景框，按 **空格** 确认导出并自动跳到下一张。已导出过的图会自动跳过。

界面为三栏布局：

| 区域 | 内容 |
| --- | --- |
| 左栏顶部 | 「导入 / 规范素材」板块：导入文件夹 / 导入文件、已导入计数、规范状态提示 |
| 左栏下方 | 素材队列：展示 `规范素材图/` 内容（标题显示「待裁剪 N / 共 M」），支持 ↑↓ 调序、点选跳图 |
| 左栏底部 | 日志面板（标题即「保存日志」按钮，点击导出 `<年月日_时分>run.log`） |
| 中栏 | 画布：fit-to-window 整图预览，窗口缩放 / 最大化时实时重新适配 |
| 右栏 | 结果放大预览、尺寸档位（大档 / 小档可编辑）、比例锁定、旋转 / 镜像 / 居中、格式与质量 |

## 三、step1 缩放规则（短边夹逼，纯等比）

夹逼区间**不是写死的**，它由你设置的两个档位自动推算：

```
下限 = min(小档宽, 小档高)      # 短边的最低要求，不足就放大
上限 = min(大档宽, 大档高)      # 短边的封顶，超出就缩小
```

按**默认档位**（大档 2560×1440、小档 1280×720）算出来就是 **[720, 1440]**。以下表格全部以这组默认值为例：

| 条件（默认档位下） | 处理 |
| --- | --- |
| `720 ≤ short ≤ 1440` | **不缩放**，原尺寸保留 |
| `short < 720` | 等比放大，使短边 = 720 |
| `short > 1440` | 等比缩小，使短边 = 1440 |

其中 `short = min(宽, 高)`。始终保留原纵横比、不裁切、不拉伸；长边允许溢出，留到 step2 取景时再决定留哪部分。

| 源图 | step1 输出（默认档位下） | 判定 |
| --- | --- | --- |
| 4000×600 | 4800×720 | 短边 600 < 720 → 放大 |
| 876×492 | 1282×720 | 短边 492 < 720 → 放大 |
| 1920×1080 | 1920×1080（不动） | 短边 1080 在区间内 |
| 3000×2000 | 2160×1440 | 短边 2000 > 1440 → 缩小 |

### 自定义档位与比例（教程）

右栏的「纵横比 / 大档 / 小档」三行都可以直接改，改完立即生效并写入 `config.json`：

| 想改什么 | 怎么改 | 连带效果 |
| --- | --- | --- |
| 输出尺寸 | 改「大档」或「小档」的宽 × 高 | step2 导出尺寸立刻变成新数值 |
| 画面比例 | 改「纵横比」的 宽:高 | 锁定状态下，两档的高按 `高 = 宽 ÷ 比例` 自动重算 |
| 夹逼区间 | 改两档的**短边**（宽高中较小的那个） | step1 的上下限随之变化 |

举例，把大档改成 2000×1200、小档改成 1000×600 后：

| 项目 | 默认档位 | 自定义档位 |
| --- | --- | --- |
| 夹逼区间 | [720, 1440] | [600, 1200] |
| 3000×2000 的 step1 输出 | 2160×1440 | 1800×1200 |
| step2 按大档导出 | 2560×1440 | 2000×1200 |

比例改成 4:3 时（锁定状态下），两档高度会按宽度自动重算：

| 比例 | 大档 | 小档 |
| --- | --- | --- |
| 16:9 | 2560×1440 | 1280×720 |
| 4:3 | 1600×1200 | 800×600 |
| 2:1 | 2000×1000 | 1000×500 |

> 纵横比「锁定」（默认开）时改档位宽度会自动同步高度；关掉锁定后可分别设置宽高，裁框就是非标准比例。
> 建议保持 **小档 < 大档**，否则夹逼区间的上下限会反过来。

## 四、快捷键与变换

| 键 | 作用 |
| --- | --- |
| `空格` | 确认裁剪并前进（唯一的推进方式） |
| `C` | 取景框一键居中 |
| `1` | 返工：把上一张裁剪的**源图**移入 `规范素材图/返工/` |
| `3` | 精修：把上一张裁剪的**成图**移入 `修改后成图/精修/` |
| `Esc` | 中断正在进行的 step1 批处理 |

变换（手动，不读 EXIF 方向）：`↺ 左转 90°` / `↻ 右转 90°` / `⇋ 镜像` / `居中 (C)`。

> 「上一张」= 最近一次裁剪导出涉及的图；首图尚未裁剪时 `1` / `3` 无操作。
> 焦点在输入框或按钮上时快捷键不触发，避免与数字输入冲突。

## 五、其他行为

- 窗口重新获得焦点时自动重扫 `规范素材图/`（在资源管理器里增删文件后切回窗口即刷新），且不会重置已经拖好的取景框。
- 「移除」按钮把文件移到 `规范素材图/已移除/`，**不真正删除**。
- step2 取景框比例跟随当前档位；横图优先保高、竖图优先保宽，最大化保留画面。
- 支持 `jpg / png / webp / bmp / tif`。主题共 4 个亮色主题（minty / everforest-light / tokyo-night-light / solarized-light），在设置里循环切换并持久化。

## 六、从源码运行

```bash
pip install -r requirements.txt
python batch_proportional_image_resizer.py      # Windows 上也可双击 run_gui.bat
```

```bash
pip install -r requirements.txt
pip install pyinstaller
pyinstaller build_exe.spec --noconfirm     # Windows 下也可直接双击 build_exe.bat
```

产物：`dist/batch_proportional_image_resizer.exe`（onefile、无控制台窗口）。已内嵌 UI 字体与 ttkbootstrap / CustomTkinter 主题资源。

## 八、命令行版（仅 step1）

`adaptive_image_resizer.py` 采用**按宽分档**规则（`>2560 → 2560`、`1920–2560 → 1920`、`1280–1920 → 1280`，宽不足 1280 且高 ≥ 720 时保持原尺寸不放大；任意档算出的高 `<720` 时兜底拉到 720，允许宽 `>2560`），与 GUI 的「短边夹逼」规则不同，两者是相互独立的工具。

> 注意：CLI 的这几个阈值是**写死在脚本里的**，不随 GUI 的档位设置变化 —— GUI 的档位可在界面改，CLI 的要改得动源码。

```bash
python adaptive_image_resizer.py --input <图片目录> --sort
#   --output <目录>     指定输出目录（默认在原目录旁生成 adaptive_output/）
#   --quality 100       输出质量 1-100（默认 100，与 GUI 版一致，无损优先）
#   --recursive         递归处理子目录
#   --sort              按 large/medium/small/kept 分子目录
```

## 九、字体说明

界面字体 `OPPO Sans UI.ttf` 由 [OPPO Sans](https://www.oppo.com/cn/design/fonts/)（21.7 MiB 可变字体）静态实例化到 `wght=600` 后按 GB2312 字集子集化而来，体积降到 1.96 MiB（-91%），中文与拉丁字形与原 SemiBold **逐像素一致**。仓库只收录这份子集，**不含 21.7 MiB 的源字体**。

OPPO Sans 官方授权个人与商用免费使用；本项目仅做子集化以缩小分发体积，未修改字形。若你的使用场景需要规避字体再分发，请自行替换为其它可商用字体：把新字体放到程序目录并把源码里的 `FONT_NAME` 改成对应族名即可，缺失字体时程序会自动回退到系统字体（微软雅黑 / Segoe UI），功能不受影响。

## 十、已知限制

- **不读 EXIF 方向**：手机竖拍但带旋转标记的照片不会自动摆正，请用变换按钮手动旋转。
- **高 DPI 圆角锯齿**：在 125% / 150% 缩放下，CustomTkinter 的圆角位图会被系统拉伸，边缘略呈阶梯状；功能不受影响。
- **仅 Windows**：依赖 Windows GDI 注册字体与拖放消息钩子。
- CLI 版与 GUI 版的 step1 规则分叉，属有意保留的两个独立工具。
