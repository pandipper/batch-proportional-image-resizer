# 批量图片等比例缩放工具 · Batch Proportional Image Resizer

一个等比例批量图片缩放器：**不裁剪、不拉伸、不填充**，只按规则把杂图归一化到固定宽度档位，方便你第二步人工裁成 16:9。

- 中文名：批量图片等比例缩放工具
- 英文名：`batch-proportional-image-resizer`

本仓库提供两个入口：

1. **图形界面版（推荐）** `batch_proportional_image_resizer.py`：把 **step1 规范素材尺寸** 与 **step2 半自动逐图裁剪** 合并为同一工具。详见下方「图形界面版」一节。
2. **命令行版（仅 step1）** `adaptive_image_resizer.py`：纯 CLI 的等比例分档缩放器，详见「命令行版」一节。

## 特性

- **按源宽分档**：`>2560 → 2560`(large)、`1920–2560 → 1920`(medium)、`1280–1920 → 1280`(small)
- **高度兜底**：算出来高度 `<720` 时，强制把高拉到 `720`、宽按比例重算（这条**优先于宽封顶**，允许宽 `>2560`）
- **最小档兜底**：源图宽 < small 档宽（默认 1280）时放大到该宽度，不再保留过小的原图
- **等比、不裁、不拉伸**：使用 PIL 的 `LANCZOS` 重采样
- 支持 `jpg / png / webp / bmp / tif`
- `--sort` 按 `large / medium / small / kept` 分目录，便于按档人工裁 16:9
- `--recursive` 可递归子目录
- **跨 Pillow 版本兼容**：内置 `LANCZOS` 兼容垫片，Pillow 9/10/11/12 都能跑，无需锁定特定版本

## 图形界面版（step1 + step2 合并）

入口：`batch_proportional_image_resizer.py`（单文件，tkinter + Pillow）。

### 运行

```bash
pip install pillow
python batch_proportional_image_resizer.py
```

> tkinter 是 Windows 官方 Python 自带的标准库，无需额外安装。Mac/Linux 若缺 tkinter，用系统包管理器补装即可。

### 工作目录（自动建在 exe 同目录）

| 文件夹 | 作用 |
| --- | --- |
| `规范素材图/` | step1「规范素材尺寸」的输出，**也是 step2 唯一输入源** |
| `修改后成图/` | step2 裁剪结果导出目录 |
| `规范素材图/返工/` | 按 `q` 把「上一张」退回此处待二次编辑 |
| `修改后成图/精修/` | 按 `E` 把「上一张」结果移入此处待精修 |

### 流程

1. **导入**：选「整个文件夹」或「多选文件」（源图留在原位置，不复制）。
2. **规范素材尺寸**：对导入的源图做等比例分档缩放，结果写入 `规范素材图/`。
3. **裁剪（step2）**：进入逐图裁剪。窗口切回焦点时自动重扫 `规范素材图/`，已裁完（结果已存在）的图自动跳过。

### 预览与取景

- 默认 **fit-to-window 整图预览**（不放大局部）。
- 裁剪框：**红框 + 内部 3×3 九宫格**，可拖移、四角缩放并锁定 16:9。
- 右侧 **实时结果预览缩略图** 显示框内实际裁出内容。

### 尺寸套装

- GUI 内可编辑三档：**大 2560×1440 / 中 1920×1080 / 小 1280×720**（持久化到 `config.json`）。
- **⚪ 套装开关**：
  - 实心（开）：按当前图高就近自动选档，COVER 缩放到该档尺寸后裁出精确档位图。
  - 空心（关）：自由自定义 W×H 裁剪，**不做任何判断**。
- 跨图 **复用锚点中心**：记录上一张框中心的相对比例，下一张自动落位，遇越界回图像中心。

### 变换（手动，不识别 EXIF）

- `↺ 左转90°` / `↻ 右转90°` / `⇋ 镜像`。

### 快捷键

| 键 | 作用 |
| --- | --- |
| 空格 | 确认裁剪并前进（唯一推进方式） |
| C | 裁剪框一键居中 |
| q | 返工：把「上一张」从 `规范素材图/` 移入 `规范素材图/返工/` |
| E | 精修：把「上一张」结果从 `修改后成图/` 移入 `修改后成图/精修/` |

> 「上一张」= 刚用空格前进离开的那张；首图无上一张时 `q`/`E` 无操作。

### 安装与打包

依赖仅 Pillow；如需出 exe，用 PyInstaller 一条命令即可（与命令行版相同）：

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole batch_proportional_image_resizer.py
```

## 命令行版（仅 step1）

### 安装

```bash
pip install -r requirements.txt
# 或
pip install pillow
```

> 图片缩放是硬需求，纯 Python 标准库做不了（没有 JPEG/PNG 解码器和重采样器），Pillow 是必需依赖，但版本不挑。

### 用法

```bash
python adaptive_image_resizer.py --input <图片目录> --sort
# 可选参数
#   --output <目录>     指定输出目录（默认在原目录旁生成 adaptive_output/）
#   --quality 90        输出质量（默认 90）
#   --recursive         递归处理子目录
```

`--sort` 会把结果按档位分到 `large / medium / small / kept` 四个子目录。

## 分档规则与实测示例

规则优先级：**宽度分档 → 最小档兜底（不足则放大）→ 高度兜底（可越过宽封顶）**。

- **最小档兜底**：源图宽 < small 档宽（默认 1280）时，**放大到 small 档宽**，不再保持原图（原「不放大保护」已取消）。
- small 档宽可在 GUI 里修改，step1 的下限随之抬升。

| 源图 | 输出 | 落档 |
| --- | --- | --- |
| 6000×4000 | 2560×1707 | large |
| 2000×1500 | 1920×1440 | medium |
| 1500×1000 | 1280×853 | small |
| 1000×900 | 1280×1152 | small（放大到宽 1280） |
| 800×800 | 1280×1280 | small（放大到宽 1280） |
| 1000×500 | 1440×720 | small（仅高兜底） |
| 5000×700 | 5143×720 | large（高度兜底越过宽封顶） |

以上实测图全部非 16:9、画面完整，正好对应脚本的分档逻辑。
